# ADR-001 · 第一阶段实现取舍

2026-09-05 · 接受

## 连接复用与业务隔离

复用用户指南指向项目的Supabase连接配置；新对象使用 `apm_`。不复制旧表全放行策略，不修改旧数据。

## 身份

原总设计考虑Supabase Auth。本阶段采用指南同类的独立访问码机制，避免要求用户改已有项目Auth设置；使用高熵访问码哈希、独立签名密钥、独立cookie、全部服务器访问。未来公开注册再引入Supabase Auth并迁移身份映射。生产部署禁用开发自动登录。

## 内容与范围

首轮70篇课程原文+14张明确设计样卡，360保持内容目标。用户要求先将课程/样卡/项目流程跑通，本阶段不以低质量批量抽取填满卡数。实时语音和AI生成管线延后，页面不得显示虚假可用状态。

## Schema简化

单一私有库先用章节、单元、来源修订、卡片修订、用户状态和事件，保留不可变版本及事务；暂不建设多课程成员、模型用量、后台队列或向量搜索。文件即规范，后续范围变化先更新spec。

## 验证

单元/集成测试验证调度、权限和幂等。用户随后明确移除Tabbit约束，改用当前可用的CUA浏览器工具验收；用户授权次一级模型进行独立验收，在代码成形后委派。

## 视觉补充

用户更新frontend-design并要求模型自主完成具有想象力的UI。保留暗面与纸卡的核心对比，修正“黑底+单一酸橙”的常见模板感：以深蓝墨色、冰川蓝、淡紫、珍珠白组成光学记忆工作室；让首页的一组半透明折叠知识卡成为唯一主视觉，其他信息收敛成有节奏的行与留白。章节的颜色帮助识别内容域，动效只响应操作与一次开场。

颜色：深墨 `#10131D`、面板 `#191E2B`、冰蓝 `#A4C7FF`、淡紫 `#C4B5EA`、纸白 `#F2F4F7`、柔杏 `#E4C3A1`。正文中文使用苹方/思源黑体可靠回退，英文标题用细腻衬线与正文对照；不用满屏大写标签或装饰性编号。

布局：左侧安静导航，首页左侧学习邀请、右侧可进入学习的折叠卡片主视觉；下方今天任务与课程轨道用非等尺寸布局；正式学习集中于一张纸卡。该补充优先于原稿酸橙色值。
