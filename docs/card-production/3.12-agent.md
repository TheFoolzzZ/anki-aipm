## 母题与实践（不入数据库）

**3.12-M1**（3–8分钟）：为跨系统调查助手设计Agent：解释四能力、动态计划和工具契约，规定权限、批准、记忆、失败恢复、停止和验收。

答案骨架：定义结果证据和允许动作，以观察驱动计划；模型输出工具请求，执行系统验证权限与参数并记录业务状态，返回后决定继续或停止；记忆带来源与有效范围，反思用真实测试或事实核验；工具超时不盲目重写，预算和无进展有停止出口；按结果/过程/成本分别验收。

评分：需逐项给出假设、证据和条件结论；只列工具名或保证一定正确不合格。允许不同方案，只要能说明代价和验证。

**3.12-T1**（15–45分钟）：T1：画任务状态图，标明规划、工具、记忆、反思如何协作，包含完成、超时未知、无进展、权限拒绝和人工接管分支；写工具输入输出/幂等规则、记忆更新删除、风险审批表，准备每种分支的输入及可观察预期。评估一组任务的结果成功、越权、重复动作、费用/延迟，并记录分母。完成判据：四能力都有实际责任与证据，风险不只停在提示文字；同一授权不反复确认，超范围变化不自动放行。

**3.12-T2**（P2，15–45分钟）：使用当前官方文档查至少3个Agent框架，记录版本/日期、控制流、工具接入、状态持久化、观测与部署约束。对同一小任务比较自写简单流程、单Agent及多Agent候选，说明分工接口和通信成本；选择须有证据，不以框架数量多或多Agent名称作优点。当前本轮未进行该外部调查，不能计已完成覆盖。

### K4 `ch03.agent.memory-freshness.001`

母题：3.12-M1；目标：正文补题；position=94；场景判断；75秒；新key rev1；来源 L220–250；L348–356；L462–462。
