## 母题与实践（不入FSRS）

M1（3–8分钟）：为多语言客服和长文档分析设计Token预算与月度费用表，说明超长处理和质量验证。

答案与评分骨架：明确完整请求输入项、输出预留及接口限制；在统一单位下分输入输出计算，并计入重试与维护；按任务选择精简、检索或分段汇总，验证信息完整性与成功任务成本；把本地估算和服务用量对账。必须同时给出计算、质量边界和未确定的服务口径，不能只提交一个月费数字。

T1：30–45分钟创建预算表，列当前模型/tokenizer版本、接口输入输出限制、用户/系统/历史/检索/工具各项、实际用量字段、当前价格与查询日期、重试及月调用量。使用中文、英文、表情、数字、代码样本对照本地估算与服务用量，解释差异；另用三句话向非技术同事说明语言成本为何依赖样本和价格。T2：20–30分钟为长文任务制定截断/摘要/检索/分段方案比较，列必须保留证据、跨段依赖、验收样本及失败回退。两项为待执行实践，不声称已有运行证据。

实践验收：产物需同时记录输入、判断依据、失败边界和下一步验证；仅复述术语不通过，尚未执行不得标记完成。
