## 3. 覆盖蓝图

业务问题：新人建立对 PM/AI PM 角色的真实认知，能判断需求真伪、与技术协作、诊断流失。先修：无。
章重点（标准§4.1 第1章）：具体行为与产出、一个工作情境、职责边界；避免职业口号。

| 蓝图项 | 内容 |
| --- | --- |
| 母题 M1（文档级，3–8分钟） | 用一款真实产品，分别举例说明需求判断、体验设计、商业变现、技术协作四类问题上的判断方法与依据（覆盖表指定四类整合） |
| 实践任务 T1（文档级，15–45分钟） | 选常用App找一个疑似伪需求功能，写出目标用户、宣称问题、证据与验证方法 |
| 子卡（发布） | 3张rev2补强 + 8张新卡，见第4节 |
| 排除项 | 职业薪资、工具清单、人物评价、过时预测（理由见台账） |

母题 M1 答案骨架：需求判断=举证责任在提议方+伪需求识别；体验=简洁非简陋、功能克制；商业=流量不等于变现（Q88 仅作反面例子，不背书结论）；技术协作=做不了的处理顺序+不挖坑四条。评分看「真实产品举证+判断方法」，不接受复述结论。
