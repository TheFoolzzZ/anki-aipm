# Recall 导航与视觉改造

2026-10-03 · 实施中。用户授权重设计课程层级、学习流程和整体视觉；奖项标准作为质量目标，不作为已获外部评审的声明。

## 交互验收

- 全站模块在顶部切换；进入知识地图、章节、课程或课程练习后，左侧显示可展开的真实章节/课程目录。可搜索全部课程、直接跳课、识别当前页。
- 面包屑显示知识地图 → 章节 → 课程 → 练习，祖先均可点击。刷新和直接访问保持当前位置。
- 课程上一课/下一课按章节位置、课程位置、ID 排序，允许跨章节并明确标注；首尾不循环，不隐式写入已读或评分。
- 每日复习保留现有 FSRS 动态队列；指定单卡练习结束后停止；`/study?lesson=<id>` 只练本课未暂停卡，每张成功评分一次后结束。无效或冲突参数不得退回每日队列。
- 自主练习评分仍更新真实复习计划、耗时和今日统计；不受每日选卡限制。评分失败不推进，重试沿用幂等键，撤销成功后恢复上一张。
- 查询参数切换重新建立本次练习；刷新会重置本轮位置，但保留已成功保存的云端记录。不得声称额外练习不影响计划。
- 阅读、已读、已学习与掌握不混淆；卡片数/课程数取真实数据，不再把扩充后的全部卡片称为首批样卡。

## 设计选择

颜色：雾白 `#F5F7F8`、纸白 `#FFFFFF`、深蓝 `#172D3A`、青绿 `#167D89`、柔紫 `#7773B2`、边界灰 `#DCE4E8`。中文以系统苹方为主，英文品牌延用 Instrument Serif；正文清晰优先，无远程字体依赖才能阅读。

顶部全站导航、276px 上下文目录、宽松内容区；课程正文集中可读宽度。知识地图用真实章节组成可点击的路线图作为主视觉，其他区域以课程行和细分组表达结构。动效仅用于当前选择、展开和操作反馈；尊重 reduced-motion。

390px、768px、1440px 目标视口；移动目录抽屉支持关闭、遮罩和 Escape；键盘焦点可见、表单命名、dialog 命名、长标题与正文安全折行。

## 保留的契约

根布局数据壳持续挂载，不因导航重新 bootstrap；FSRS/API/数据库结构和现有卡片身份不改。已有课程图片与卡背解析展示保留。生产发布另行执行，不修改用户学习数据来制造演示进度。

## 验证

类型检查、现有测试、导航/范围行为测试、生产构建；实际浏览器验证课程选择、目录/搜索/面包屑、跨章上下课、模式切换与响应式。真实评分集成必须有隔离数据证据，模拟不得替代。


## 2026-10-08 双主题与品牌标题

用户要求：保留新版顶部导航、上下文课程目录、面包屑和课程跳转布局；把旧版背景、配色及字体气质作为可切换主题，设置页可选择。

- 品牌沿用旧版DM Sans无衬线方式，35px、较舒展字距，文字和标记不收缩、不折行；手机30px。扩大标题不缩改全站导航结构，窄屏导航沿用横向滚动。
- “雾白”保留新版雾白/纸白、深蓝与青绿；“深墨”恢复旧版`#10131d`背景、`#f2f4f7`文字、`#969dab`次级文字、`#a4c7ff`冰蓝、`#c4b5ea`柔紫与`#e4c3a1`暖色。经典标题字重500，衬线副标题使用原Instrument Serif/Songti后备。字体资源沿用既有导入，无新增字体依赖。
- 主题只作用于颜色、字体和表面样式。共享原导航组件、宽度、层级与路由；深色学习空间保留浅色练习卡/卡片详情，局部覆盖文本与控件颜色保证可读。
- 设置页的主题选项独立于学习设置表单，原生radio支持方向键，点击立即生效。在此浏览器保存`recall.theme`，不写数据库、不修改学习设置版本或进度；跨设备同步不作承诺。默认雾白，已选主题刷新/导航后保留。
- 根布局在首次绘制前读取白名单主题，按本仓库Next.js防闪烁指南使用html主题属性；开发重挂载重应用。未知值回到雾白，存储不可用时仍可切换，并如实提示无法记住选择。
- 验证：真实页面的两种主题切换/刷新/键盘、1440/768/390标题不重叠且无横向溢出、移动抽屉配色、正文及展开卡背。类型检查、23测试、正式构建通过；未新增数据库对象或部署线上。证据见[导航验证追加记录](../verification/navigation-and-visual-refresh.md)。
