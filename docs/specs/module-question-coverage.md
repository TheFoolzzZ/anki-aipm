## 出题深度标准

每道进入学习系统的题，均应标注来源（原题/原清单改写/新增补题）、模块和能力层级，并满足下列最低标准：

| 层级 | 回答要求 | 适用题型 |
| --- | --- | --- |
| L1 概念辨析 | 说明定义、边界和与相邻概念的区别 | 总结转化题、技术基础题 |
| L2 情境判断 | 给定业务背景，在至少两个方案间选择并说出条件 | 原生思考题、自查改写题 |
| L3 方案设计 | 给出目标、流程/架构、指标、风险与兜底 | 产品设计、Agent、RAG、商业化题 |
| L4 证据复盘 | 用数据或假设验证选择，解释失败信号和下一轮动作 | 评估、成本、风险、运营题 |

原生的「明确问题」至少按 L2 作答；自查条目至少要求 L2 的项目证据；仅总结和无题模块补题时，至少覆盖一题 L2 与一题 L3。第 9 章可优先抽 L2 产品洞察题，再用 AI 产品场景重写为 L3；不把原文答案当作唯一正确答案。
